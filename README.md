# React Shop
Shop for a variety of products in React.

This is made solely for educational purposes; its aim is to show hooks and filters in React.

<img src="/docs/screen-react-shop.png" width="550px" alt="screenshot">


## ✅ Features

- Show All products from JSON file
- Filter products by category
- Filter product by price range 

**Use React Context to:**
- Add item to Cart
- Remove item to cart
- Change product quantity 
- Use localstorage to persist data.

_(All static)._

## ⚙️ Tech Stack

- React 19
- Vite 7.1
- Tailwindcss 3.4


## 💾 Installation

Install and run

1. Clone and move to folder
```bash
$ git clone git@github.com:abrahamuchos/react-shop.git
$ cd react-shop
```

2. Install dependencies
```bash
$  npm install
```

3. Run dev `npm run dev` or run to production `npm run build`
